# 달빛 4.1.0 릴리즈 노트

**직전 출시**: 4.0.6 (build 9, `deploy-Dalbit-4.0.6-9`)
**이번 범위**: 그 태그 이후 전부 — 피드백 허브 이관, 사용 통계·크래시 가시성, 디자인 개편,
첫 실행 안내 복원, 대규모 정리.

버전을 4.0.7이 아니라 **4.1.0**으로 올린 이유: 사용자에게 새 화면이 셋(첫 실행 안내, 달빛
이야기, 나의 기록) 생겼고 앱 전반의 표면 디자인이 바뀌었다. 패치로 부르기엔 폭이 넓다.

## App Store 「새로운 기능」 문구

그대로 붙여 넣을 수 있게 준비했다. **사용자가 볼 수 있는 것만** 적었다 —
내부 통계·리팩터링은 여기 넣지 않는다(사용자에겐 의미가 없고, 심사자에게는 혼란만 준다).

### 한국어

```
처음 오신 분들을 위한 안내가 생겼어요.

• 첫 실행 안내 — 달빛이 어떤 앱인지, 어떻게 쓰는지 짧게 보여드려요.

  (설정에서 언제든 다시 볼 수 있어요)
• 나의 기록 — 달빛과 보낸 시간, 연속으로 들은 날을 모아 봤어요.

그리고 밤에 보기 좋게 다듬었어요.

• 화면 곳곳을 유리처럼 바꿔, 뒤로 흐르는 별이 가려지지 않아요.
• 버튼과 글자의 대비를 손봐 어두운 곳에서도 또렷해요.
```

## 사용자에게 보이는 변경

### 새 화면

| 화면 | 위치 | 내용 |
|---|---|---|
| 첫 실행 안내 | 최초 1회 (건너뛰기 가능) | 왜 이 앱인가 4장 |
| 달빛 이야기 | 설정 → 맨 위 | 효용 + 제작 노트 6편 + 안내 다시 보기 |
| 나의 기록 | 설정 | 누적 청취·연속일·잠든 것 같은 밤 (이 기기에만 저장) |

첫 실행 안내는 **조작법을 설명하지 않는다.** 그건 홈에서 달을 눈앞에 두고 기존
제스처 코치마크가 맡는다 — 순서(왜 → 어떻게)를 코드로 보장했다.

### 고친 것

- **달 그림자가 실제로 기울지 않던 문제.** 애니메이션은 돌고 있었지만
  `easeInOut(1125초)`라 24초에 위상이 0.0014 움직였다 — 사람 눈엔 정지 상태였다.
  `linear(480초)`로 바꿔 분당 위상 0.22(터미네이터 기준 약 27pt)로 움직인다.
- **한/영 혼용.** 우주 프리셋 13개가 지역화 분기에 빠져 한글 원문이 그대로 나왔다.
  프리셋 제목은 시드 시점 언어로 저장돼 굳으므로, 언어가 바뀌면 다시 시드하도록 고쳤다.
- **주 버튼 대비.** 다크 모드에서 흰 글씨 대비가 2.2:1로 WCAG AA(4.5:1) 미달이었다.
  진한 그라데이션으로 바꿔 4.8:1 확보.
- **보관함 검색 정렬.** 가로 여백이 이중으로 걸려 검색창만 24pt 더 들어가 있었다.

### 디자인

우주 배경 위에 불투명한 판을 얹던 것을 전부 유리로 바꿨다(카드·설정 행·세그먼트·
보조 버튼·원형 버튼·개수 칩). 타이머 화면의 SF Symbol 배지는 빛으로만 그린 초승달로 교체.

## 내부 변경 (사용자에게 안 보임)

- **사용 통계**: 익명 집계를 공용 허브(FeedbackHub)로 수집. 이번에 **사용 시간·빈도**를
  추가했다 — 최근 7·30일 청취 분, 들은 날 수, 세션 수, 마지막 청취로부터 지난 일수,
  역대 최장 연속일, 시간대 분포. 자세한 건 `docs/USAGE_STATS_HUB.md`.
- **크래시 가시성**: MetricKit 진단을 같은 허브로. 설정 → 안정성에서 버전별 건수와 콜스택.
- **원격 킬스위치**: LeeoKit 2.9.0. 심사 없이 수집을 즉시 멈출 수 있다.
- **테스트**: `DalbitTests` 신설, 유닛 테스트 50개. 잠든 판정·고아 세션·리텐션·퍼널·
  사용 시간/빈도 계산을 검증한다.
- **정리**: 도달 불가능한 화면 17개 파일(3,109줄) 삭제, 미사용 번역 키 151개 제거,
  기능별(feature-first) 폴더 재편. 69개 17,477줄 → 62개 14,142줄.

## 제출 전 확인할 것

- [ ] **App Privacy 설문 갱신** — 이번 버전부터 데이터를 보낸다.
      *Product Interaction*(Usage Data)과 *Crash Data* 둘 다, 목적은 Analytics/App Functionality,
      **사용자와 연결되지 않음**, 추적 아님(ATT 불필요).
- [ ] **개인정보 처리방침 반영** — `docs/privacy.html`을 고쳤다. GitHub Pages
      (`https://m1zz.github.io/Dalbit/privacy.html`)에 배포됐는지 확인.
      시간대 수집 문구가 새로 들어갔다.
- [ ] **CloudKit 스키마 Production 배포** — `UsageSnapshot`·`UsageEvent`·`CrashReport`,
      그리고 킬스위치를 쓰려면 `RemoteFlags`. 절차는 `docs/USAGE_STATS_HUB.md`.
      배포 전에는 개발자 통계 화면이 "읽지 못했어요"로 뜬다(정상).
- [ ] **실기기 확인** — 아래 항목은 시뮬레이터에서 확인이 어렵거나 불가능하다.
      - 첫 실행 안내 → 제스처 코치마크 순서 (앱 삭제 후 재설치)
      - 달 그림자: 재생 후 4분이면 반달, 8분이면 그믐
      - 크래시 진단은 실기기 + 하루 정도 지나야 올라온다
      - 잠금화면 재생 정보, 백그라운드 재생

## 알려진 제약

- MetricKit 진단은 iOS가 하루 한 번꼴로 묶어 보낸다. 실시간 알림용이 아니다.
- 「잠든 것 같은 밤」은 **추정**이다(타이머 완주 또는 30분 이상 방치 종료).
  수면을 측정한 값이 아니므로 마케팅 문구로 옮길 때 단정하지 말 것.
- 이번 릴리즈에서 **온보딩 화면을 새로 썼다.** 구 온보딩(4장 일반 문구)은 삭제됐다.

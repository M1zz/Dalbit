나만의 완벽한 백색소음을 만드는 iOS 앱

여러 자연의 소리를 레이어처럼 겹쳐 나만의 백색소음을 만들고, 저장하고, 언제든 다시 들을 수 있습니다. 수면·집중·명상에 맞는 소리를 직접 디자인하세요.

주요 기능

  • 🎵 여러 소리를 겹치는 멀티 레이어 믹싱
  • 🔥 캠프파이어 비주얼
  • ⏱️ 수면 타이머
  • 💾 나만의 조합 저장
